# ⛔ 阶段验收包：v57 —— **已作废，不通过**

**首行判定：v57 上板功能不通过，且是"每次不一样"的时序失效。不得作为基线、不得使用。v39 仍是唯一可用基线。**

⟶ **以 [`VERDICT_REJECTED.md`](VERDICT_REJECTED.md) 为准。** 本目录的其余文档保留作为过程记录，其中 `00_ACCEPTANCE.md` 的"可以接受"结论**已作废**。

## 一句话

$$\text{WNS} = +0.206\,\text{ns},\ \text{TNS} = 0,\ \text{违例端点} = 0 \quad\not\Rightarrow\quad \text{硬件正确}$$

xsim 12/12 逐字节且逐拍相同（逻辑对），但上板两次独立 load 结果**互不相同**且都错 ⇒ **STA 漏了或错误豁免了一条真实路径**。

## 为什么保留这个包而不删

1. **证据价值**：它记录了"报告干净但硬件不成立"的完整案例（WNS +0.206 却上板错，且非确定性）
2. **时效刀 7 的结论依然成立**：它确实把 10 ns 从 −1.998 清到 +0.206，**时序报告是真的改善了**
3. **但它换不来可用位流** ⇒ 与 T-98 里 v50 的 `WNS +0.113` 假安全同类
