# v57 —— 最终版本（运行点：**75 MHz**）

**首行判定：v57 @ 75 MHz 为最终交付版本。10 ns 口径 WNS +0.206 / TNS 0 / 违例端点 0；板端 75 MHz 实测 3/3 sha1 命中；256² 墙钟 6.198~6.234 s。**

> 用户决定（2026-11-03）：**按 75 MHz 上板，慢一点无所谓，这就是最终版。**
> 100 MHz 不可用（已实测 0/7，且不同实现同样失败），75 MHz 是它的最后一个可用点。
> ⚠ **冻结 sha1 只在同 numpy 版本/同输入下可比**（`x0_sha1` 不同 ⇒ 环境差异，不是网络错）：见 `07_KNOWN_LIMITS.md` §7。

## 为什么是 75 MHz 而不是 100

| 频率 | v57 | v39（对照）|
|---|---|---|
| 150 MHz | 未测（6.667 ns 口径 −3.07）| ✅ 5.25~5.32 s |
| 100 MHz | ❌ **0/7**（7 次 sha1 互不相同；另一实现 0/3 且越界写）| ✅ 4/4 |
| **75 MHz** | ✅ **3/3（另实现 4/4）** | ✅ |
| 50 MHz | ✅ 2/2 | ✅ |

⇒ **75 MHz 是 v57 的最后一个可用点**，已按用户决定定为最终运行点。
