## 4. ★ 一个真实存在的独立缺陷（本次顺手查出，与"是否导致挂死"无关）

`system.xsa` 的 `ps7_init` 里 USB0 时钟**没有开**：
```
mask_write 0XF8000154 0x00003F33 0x00000A02
```
`0xF8000154` = USB0_CLK_CTRL，`value bit[0] = CLKACT = 0` ⇒ **USB0 核心时钟被门控关闭**。
（`ps7_init_gpl.c` 里 `USB0_CPU_1XCLKACT = 0x1` 只说明 APB 时钟开了，不是 USB 核心时钟。）

$$\Rightarrow\ \text{即使 DT/驱动全对，USB0 也}\textbf{不可能工作}$$
$$\Rightarrow\ \text{但注意：} \texttt{drivers/usb/chipidea/ulpi.c} \text{ 的 } \texttt{ci\_ulpi\_wait} \textbf{有 10 ms 超时} \Rightarrow \text{不会无限挂死}$$
$$\Rightarrow\ \Rightarrow\ \textbf{不能}用"USB 卡死"解释整板不启动 \Rightarrow \text{这条要单独修，不能当挡箭牌}$$

## 5. 仍未定位（需要串口或二分）

$$\Rightarrow\ \text{启动链上到底卡在哪：FSBL / U-Boot / 内核早期}$$
$$\Rightarrow\ \text{"1000 Mbps" }\textbf{不能} \text{区分"卡在 U-Boot"与"FSBL 就没起来"}$$
$$\quad\ \text{因为 PHY 只要上电、没被软件配置，默认自协商就是 1G}$$
$$\quad\ \text{而旧镜像在 Linux 下被配成 100 Mbps}$$

## 6. 下一步（按代价排）
