## 3. 第 3 步：四个非 conv 算子

v53 BD 里**只有 `bin_unit_0`（`UNIT=0` = conv_core）**，没有 `bin_rprelu`/`bin_sam`/`bin_interp`
实例（hwh 的 `bin_unit_0` 无 `UNIT` 参数）；`bin_net` 的 `capabilities()` 也写明这三个 PL 单元
"没有 PS 驱动"。所以整网里它们**都走 PS**，本步测的是**板端 PS 实现 vs 主机 numpy**（跨架构，§7.4）。

| 算子 | 真实形状（NetPlan(128,128) = 64² 特征图） | 结果 |
|---|---|---|
| **interp** ×7 | (48,64,64)→(48,32,32) scale0.5；→(48,16,16) scale0.25；48:32→64、16→64；64:32→64 scale2；192:16→4；96:16→32 | **7/7 逐字节对**（板端 sha1 == 主机 sha1）；**ARM 现场编译的 `bilinear_c_armv7l.so` == numpy** 7/7，快 1.8~8.6×（如 10.6 vs 49.3 ms） |
| **eca** ×4 | C=144/288/576/192，9-tap 真实权重（`fp_layers`） | 中间阶段 `m`(mean)/`y`(dot+relu)/`z`(dot) **逐位全同**；只有 **`w`=sigmoid 差 ≤2 ULP**（9%~18% 通道），故 sha1 与主机不同 |
| **sam** ×3 | 48/64/96 通道 @64²/64²/32²，`w` 由**真实 eca** 在**真实 cat3**（3C 通道）上算出 | 输入 `x/y0/y2/y4` 逐位全同；`w` 继承上面 ≤2 ULP；输出最大 `|Δ|=1.4e-06`（量化到 i8 远不足 1 LSB）；**2 线程 == 1 线程逐字节**（3/3） |
| **rprelu** | 融合在 227/227 conv 收尾 | conv golden 逐位包含 RPReLU ⇒ 由第 2 步覆盖；另算"关掉 RPReLU"的 golden 统计**依赖字节**：`c48_o96` 87 416、`c160_o48` 188 600、`c224_o64` 256 484、`c416_o96` 345 799、`c512_o192` **634 383**（均 >0 ⇒ 非空转） |

### 3.1 eca/sam 的差异到底在哪（`t130b_cmp.json`，38 个中间阶段逐元素）

| 阶段 | 差异元素 | 说明 |
|---|---|---|
| `x`（输入）、`m`（沿 HW 求均值） | **0 / 38 个阶段全 0** | numpy 归约在 ARM 与 x86 **逐位相同**（排除"归约顺序"这个怀疑） |
| `y`、`z`（9-tap 串行累加） | **0** | `_windowed_dot_exact` 的串行 f32 累加逐位相同 |
| **`w` = `1/(1+exp(-z))`** | 17/144、39/288、94/576、25/192 … | 全部 **≤2 ULP**（max `|Δ|=5.96e-08`）⇒ **`np.exp` 的 libm 实现差异**（x86 glibc vs ARM） |
| sam `out` | 14.7%~22.6% 元素 | 由 w 的 1~2 ULP 传播，max `|Δ|=1.43e-06`（值域 [-8,8]，相对 ≈1e-7） |

**这条对父代理很关键**：**主机侧算出的整网 golden 只要经过任何 eca/sam，就不可能再与板端逐字节相同**
（`exp` 的位级实现不同）。下游 i8 量化**只在恰好落在舍入边界时**才翻 1 LSB ⇒
"±1 LSB、个别字节、位置随重跑漂移"这类现象**存在一个纯 PS 的宿主**。
⇒ 判 128²/256² 的错**必须用板端自算的 golden**（或板端 vs 板端 A/B），不能用主机 numpy 的输出当逐字节参照。

## 5. 结论（形状维度）

1. 整网真实的 `(cin,cout,k,s)` 组合，**盒外 35 个 / 115 层全部逐字节正确**（含 `cout=192` 的 24 组回绕、
   `cin=544` 的 `cb=9`、两个 s=2 下采样层、所有 `cout>cout_prev` 的升维层）。
2. **`k=5` 整网不存在**；`cout=96/192` 的真实 cin 与任务书假设不同（§1），已按真实值测。
3. 单层 + 形状这两条维度**已经没有未知量**；剩下的只能是**跨 op 上下文**（T-121/T-124/T-127/T-128/T-129
   已逐条排除打包、重叠、流水、arena、槽数）。
4. 唯一新发现是**主机 golden 的 `exp` 口径问题**（§3.1），它足以制造"±1 LSB、非确定"的假象。
