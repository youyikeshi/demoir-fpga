C. 板上错误形状（T-96 json 重算）：
   - 非确定性：c48 1381 vs 1353；c112 24476 vs 24856；c176 18540 vs 19222 字节不符
   - 同像素多通道：c112 首批 8 错字节 pix 全 = 12，chan 1/2/4/6（g5）、2/4/6（g6）、2（g7）
   - 平均 26/64 通道/像素（24476/932）=> 错的是"该像素共享的 64-bit 激活字"
   - 系统性主格 chan≡2 (mod 8) = 16-lane 下每组 lane2 与 lane10（两半字的同一字节位）
   => 不再是"per-lane 参数错"；指向"激活字读错"。而 A/B 已证明仿真里读不坏。

D. 吞吐（只诊断，未改）
   - 板上每 8B 写 beat 的拍数：20.03 / 20.28 / 22.13 / 20.43 / 20.03（5/5 层，恒定墙）
     cyc ≈ 20 × (ceil(cout/8)·Hout·Wout)
   - AW 合并：v8 = 7.80~7.88 beat/AW（1049~1039 笔）；v16 = 1.00 beat/AW（8192 笔）
     => 16-lane 的 beat0/beat1 在两个相隔 Hout*Wout*8 B 的平面交替，链被打断
   - FIFO 深度扫描（sim，-d V97_BF=，RTL 未动，c240）：
        BF=16 总拍 41728 / 停核 24710 ; BF=24 41634/24547 ; BF=32 41479/24382 ; BF=64 41407/24095
     => 16→64 只省 0.8% 拍；FIFO 深度不是约束
   - 不停核条件：产生 1 beat/(K/2) 拍 vs 排空 1 beat/20 拍 => 需 K>=40；
     本网 K=9,18,27,4,8 全 <40 => **没有任何有限深度能不停核**；只有提高排空速率（恢复 burst 合并）
   - 实测停核占比（sim/v16）：c240 24710/41216 = 60%；c48 12502/55262=23%；c512 高
