## 3. ★ 根因级发现：部署网络**近乎与输入无关**

四张完全不同的输入（噪声 / 照片 / 两张文字），端到端统计：

$$\boxed{\ \overline{out} = 0.148\;\overline{in} + 0.310\quad (R^2 = 0.944)\ }\qquad \frac{\sigma_{out}}{\sigma_{in}} = 0.155$$

| 输入 | 输入均值 | 输出均值 | 线性预测 |
|---|---|---|---|
| 噪声 seed1 | 0.500 | 0.376 | 0.384 |
| 照片 `0000` | 0.216 | 0.344 | 0.342 |
| 文字 `0094` | 0.681 | 0.409 | 0.411 |
| 文字 `0049` | 0.598 | 0.408 | 0.399 |

$$\Rightarrow\ \textbf{DC 增益 } 0.148\ (\text{正常复原网应 } \approx 1.0)\ \Rightarrow\ \text{输出被"压扁 + 抬偏置"，这就是一片灰的来源}$$
$$\Rightarrow\ \text{它与 } \texttt{validation.json}\ \text{自报的分层误差同向：}\ \texttt{act\_quant.rel\_rms}=0.266,\ \texttt{t\_quant.rel\_rms}=0.305$$

**这不是板子/PL 的错**：主机 numpy 参考（同一输入、同一权重、纯 CPU）给出
`min=0.0213 max=0.6767 mean=0.3439`，与板端 `0.02133/0.67666/0.34389` **同量级**（`host_ref_real.py`）
⇒ 缺陷在**部署共用的 int8/二值数学**里，PL 只是忠实地算出了它。

$$\Rightarrow\ \text{v57/v58 的验收只比 }\textbf{sha1（自己跟自己比）}\Rightarrow \text{这一类"数值对、语义错"的问题}\textbf{结构上看不见}$$

## 4. 关于 GT（父代理要求的 PSNR）—— **本轮不能用**

`0000/0094/0049` 的 `moire` 与 `gt` **不是像素级配准**的：全图同位置 `corr=0.57`，
中心 256² 裁块里 moire mean=173.7 而 gt mean=**244.7（几乎全白）**，`PSNR(moire,gt)=7.58 dB`。
（`0000` 好一些：corr=0.92。）⇒ PSNR-vs-GT 反映的是**配准/光度差**，不是去摩尔纹效果，**不作为判据引用**。
