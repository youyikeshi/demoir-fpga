## 0. 一句话结论

32 个 oc 车道、II=1（每拍 1 个 ic，32 路 8×8 乘 + 32 路 26 位加同拍），
**收尾 3 拍并行并与下一块重叠**，权重整层 4 KB 双 bank 驻留（每层只装一次）。
稳态每 `(pixel, 32-oc)` 块 = **`cin` 拍**（任务书目标 `cin+3`）；k1_64x64 黄金形状
理论 **81,920 拍 + 装载/排空 ≈ 82.4k**，是 `targets.tsv` 里 HLS cosim 基线
531,437 的 **0.155×**。

**第一轮实测（2026-10-23 20:33，主控跑的）**：`k1_64x64` **82,272 拍** vs
HLS 基线 531,437 ⇒ **0.155×（6.5× 提速）**，与设计目标 81,920+overhead 吻合；
逐字节 31,429/40,960（9,531 错，23.3%）。**功能 bug 已定位并修复两处**：
① `wl_din` 声明成 32 位，把每个权重 beat 的高 4 字节截掉（一半 MAC 丢权重）；
② 块边界 `issue` 停顿时 `last_a` 不清 0，可能触发假快照。修复后待主控复跑。

**覆盖范围必须先说清楚**：本版按任务书固定 `cin≤64, cout≤64`，只覆盖
**16/132 个 k=1 层**（1.446 s / 27.486 s = **5.3%** 的 k=1 实测时间，MAC 3.8%）。
网络里没有 (64,64) 这个真实形状；这 16 层是 **(64,16)×12 + (48,16)×4**。
k=1 最大的时间块 (224,64) 19.4%、(160,64) 10.6%、(208,48) 10.3%、(256,96) 6.3%
都要求 `cin>64`（最大 352），本版装不下。数据见 §8。

## 1. 接口

端口与契约 §3 **逐字一致**（`m_axi_in_*` / `m_axi_w_*` / `m_axi_b_*` /
`m_axi_out_*` 各一组；`ctrl_*` 一组）。参数：

| 参数 | 默认 | 作用 |
|---|---:|---|
| `CIN/COUT/W/H/PAD/STRIDE/DIL/RELU` | 64/64/320/320/0/1/1/1 | 与契约同名；本版**运行时形状走 `ctrl_*`**，前 4 个只是默认/上界 |
| `LANES` | 32 | oc 车道数 |
| `CIN_MAX` | 64 | 运行期 cin 上界 ⇒ 每 lane 权重 2×8 个 64-bit 字 |
| `COUT_MAX` | 64 | 运行期 cout 上界 ⇒ 2 个 oc bank（2×32 lane） |
| `NBUF` | 4 | 输入像素缓冲数（预取深度） |
| `OBUF_N` | 4 | 输出块队列深度（每块 4 个 oc 组） |

运行期字段：`ctrl_cin/cout/h/w/shift` 在 `ctrl_start` 上升沿锁存；`PAD/STRIDE/DIL`
无运行期寄存器（k=1 恒 0/1/1）；**RELU 是编译期参数**（默认 1，线性层需 `RELU=0`
重出一版）。

数据格式（契约 §2）：
- 激活 C8：`addr(c,y,x) = (c/8)·H·W·8 + y·W·8 + x·8 + (c%8)`，一个像素的 8 通道连续 8 字节；
- 权重 k=1：`weight[oc][ic]`，每 (oc,ic) 1 字节；本版按 `cin/8` 个 64-bit 字整读；
- 输出 C8，`cout` 补齐到 8 的倍数，尾部补零通道写 0（PS 侧不读）；
- 输出标度：`clamp((acc + bias) >>> shift, 0, 127)`（RELU=1），acc 26 位有符号。

## 2. 结构

```
                      ┌──────────────────────────── 权重双 bank（整层驻留，每层 4 KB）──────────────┐
 DDR ──m_axi_w──► 权重装载 FSM ──► bank0: 32 lane × 8 组 × 64b   (oc 0..31)                          │
                      │            bank1: 32 lane × 8 组 × 64b   (oc 32..63)   ← pass0 期间装好      │
 DDR ──m_axi_b──► 偏置装载 FSM ──► bias0[32]/bias1[32]（每 lane 一个 32b 寄存器，无读地址 mux）        │
                      │                                                                              │
 DDR ──m_axi_in─► 像素预取 FSM ──► 4 × 512b 移存器（像素缓冲 ring）                                  │
                      │              每拍右移 8b ⇒ 最低字节 = 当前 ic 的 p（32 lane 广播）            │
                      ▼                                                                              │
        ┌──────────────── 计算流水（II=1，3 级）────────────────┐                                   │
        │ A: p / wmem[{bank, ic>>3}] / parity / last / pix_off  │                                   │
        │ B: 32 × (p × w[ic&7])      8×8 signed → 16b           │                                   │
        │ C: 32 × 26b 奇偶双链累加（每条链 2 拍循环依赖）        │                                   │
        │    last 拍：快照 ep_e/ep_o + 清 0（下一块无缝开始）    │                                   │
        └───────────────────────────┬───────────────────────────┘                                   │
                                    ▼                                                               │
        ┌──────────────── 收尾（3 拍，32 路并行，不是循环）─────┐                                    │
        │ E1: sum = ep_e + ep_o                (27b)            │                                    │
        │ E2: v   = sum + bias[blk][lane]      (32b)            │                                    │
        │ E3: v >>> shift → ReLU → sat8 → 拼 4 个 oc 组(64b)    │                                    │
        └───────────────────────────┬───────────────────────────┘                                   │
                                    ▼                                                               │
                    输出块队列（4 块 × 4 组 × {addr,data}）──► m_axi_out（8 字节/笔，AWLEN=0）
```

### 2.1 为什么这样切

- **bank 号是 generate 常量**：每个 lane 一个独立的 `wmem[0:15]`（`{bank, ic>>3}`），
  没有运行期 bank 选择 mux；这是 `03_weight_path.md` §7.3 的"铁律"。
- **权重地址只有 `ic`**：`{blk_r, ic_cur[5:3]}`，读口 1 拍同步读出 64-bit 字，
  由 `sel_a = ic[2:0]` 选字节；32 lane 同拍出 32 字节。
- **收尾没有循环**：`04_mac_array.md` §4.3 的 21 拍来自 `LOOP_730_36` 是
  trip=16 的流水循环；本版 32 lane 的 E1/E2/E3 全部并行，固定 3 拍。
- **权重不重装**：HLS 每 `(y, 列块, ocb)` 重装一次；本版每层只装一次
  （`cin·cout` 字节 = 64×64 = 4 KB），pass0/pass1 各用一个 bank。

### 2.2 关键流水时序（k1_64x64）

```
cycle 0..63     pass0 pixel0: ic=0..63 逐拍发射（每拍 32 MAC）
                 ic=0   的乘积在 edge 3   进累加器
                 ic=63  的乘积在 edge 66  进累加器 + 快照（last_b）
edge 67         E1（sum = acc_e+acc_o）
edge 68         E2（+bias）
edge 69         E3（>>>shift/ReLU/sat8）+ 拼 4 组
edge 70         push 输出块队列
cycle 64..127   pixel1 已在上一个 last 后**无缝开始**（块周期 = cin，无气泡）
```

即：收尾 3 拍完全藏在下一块的 64 拍里，稳态块周期 = `cin`。

## 3. 每层拍数推导

记 `P = H·W`（像素数）、`B = ceil(COUT/32)`、`L = CIN`。

```
计算：      P × B × L                       （II=1，收尾重叠）
装载：      lane_lim0+L/8 … ≈ 32×(L/8+2) + ceil(COUT/2)   （bank1 与 pass0 重叠）
像素预取：  每像素 ceil(L/8) 笔 1-beat；8 组 ≈ 16 拍/像素，预取 3 像素深
排空：      最后一块 E3→write→B ≈ 几十拍
```

| 形状 | P | B | 计算拍 | 装载/排空（估） | 合计（估） | @150 MHz |
|---|---:|---:|---:|---:|---:|---:|
| **k1_64x64 黄金向量**（H=2,W=320,cin=64,cout=64） | 640 | 2 | 81,920 | ≈ 450 | **≈ 82.4k** | 0.55 ms |
| 固定形状全幅（H=W=320,cin=64,cout=64） | 102,400 | 2 | 13,107,200 | ≈ 500 | **≈ 13.11M** | **87.4 ms** |
| 真实覆盖层 (64,16)（H=W=320,cin=64） | 102,400 | 1 | 6,553,600 | ≈ 400 | ≈ 6.55M | 43.7 ms |
| 真实覆盖层 (48,16)（H=W=320,cin=48） | 102,400 | 1 | 4,915,200 | ≈ 400 | ≈ 4.92M | 32.8 ms |

对比：

- **HLS 结构值**：每 (pixel, 16-oc) 块 `cin+23` ⇒ k1_64x64 = 640×4×87 = 222,720 拍
  （纯计算+收尾，不含 DDR/填充）；本版 82.4k = **0.37×**；
- **HLS cosim 基线**：`tools/targets.tsv` 的 531,437 拍（同一黄金形状，含填充/写回/DDR）；
  本版 ≈ **0.155×**（6.4× 快）。这个基线里还含本版彻底消掉的 237 MB 权重重装中的一份。
- 每层权重量：本版 `CIN·COUT` 字节一次；HLS `cin·cout·Hout·ceil(Wout/64)` 字节。
  对 (64,16) 层：HLS 每层 1.638 MB vs 本版 1,024 B ⇒ **1600×** 少搬；
  对这 16 层合计 HLS ≈ 24.6 MB，按成本模型 2.76 拍/字节 ≈ 67.9 M 拍 ≈ 0.45 s @150 MHz，
  正好是该 16 层实测 1.446 s 的 ~31%（与 `03_weight_path.md` 的 34.6% 同量级）。

> 拍数口径与任务书的 `pixels/16 × (cin+3)`：该式子按 16-oc 块算应为
> `pixels × ceil(cout/16) × (cin+3)`；本模块 32 lane，对应
> `pixels × ceil(cout/32) × (cin+3)`。k1_64x64 下 = 85,760 拍，本版目标 82.4k
> （`cin` 而非 `cin+3`，因收尾已重叠），比值 **0.96×**。

## 4. 权重/偏置装载与 ping-pong

```
bank0 (oc 0..31)  装载：32 笔 AR（每 oc 一笔，ARLEN=cin/8−1），每拍 1 个 64-bit 字
                  ↓ bank_ready[0] = 1
pass0 计算（读 bank0）  ────────────────────────────────┐
                  ↓ 同时                                  │ 权重装载 FSM 继续
bank1 (oc 32..63) 装载：同上                              │
                  ↓ bank_ready[1] = 1                    │
pass1 计算（读 bank1） ◄──────────────────────────────────┘
```

- `cin % 8 == 0` 才能按 64-bit 字装；本版所有覆盖层都满足（网络 132 个 k=1 层
  `cin` 全为 8 的倍数，已核对）。
- `cout < 32`（如真实的 (64,16) 层）时 `wl_lane_lim = cout`，只装实际存在的 oc，
  不会读到 `weight.bin` 之外。
- 偏置一次装完 64 个 int32（每拍 2 个），bank0=oc0..31 / bank1=oc32..63；
  **每 lane 一个 32-bit 寄存器对**，收尾同拍取 32 个 bias，不存在 HLS 的
  "每拍读 1 个 bias"串行瓶颈。

## 5. 输入预取

- 每个像素 `ceil(cin/8)` 笔 1-beat（C8 的组步长 `H·W·8`），一次 fetch 只发一个
  像素的 AR；TB/从机的 `arready` 在 burst 期间为低时自然等待。
- 4 个像素缓冲 ring，最多领先 3 个像素；每像素计算 `cin` 拍（64），预取 8 组约
  16 拍 ⇒ DDR 延迟被完全藏住。像素缓冲是 512-bit 移存器，计算时每拍右移 8 bit，
  最低字节就是当前 ic 的激活值（32 lane 共用同一根 p 广播）。
- 二 pass 制（oc 块外层）会**把输入读两遍**：k1_64x64 共 2×640×8 = 10,240 笔
  单拍读 = 80 KB；相对 82.4k 拍的计算可以忽略。换来的是 pass 内权重 bank 固定、
  不需要每像素切 bank。

## 6. 资源估算（**未综合，仅为结构估算**）

| 项 | 估算 | 依据 / 风险 |
|---|---:|---|
| 8×8 乘法器 | 32 个 ⇒ **32 DSP48**（若 Vivado 全推 LUT：32×41 ≈ 1.3k LUT） | 红线 DSP ≤ 60 ✅ |
| 权重 bank | 32 lane × 16 word × 64 bit = 32,768 bit **分布式 RAM** ≈ 2.0–2.2k LUT | `(* ram_style="distributed" *)`。**若被推成 BRAM：32 个小 RAM ≥ 32 BRAM18，超红线 30** ⇒ 综合时必须确认是 LUTRAM |
| 输入缓冲 | 4×512 = 2,048 FF + 装载 mux ≈ 0.3k LUT | |
| 累加器 | 32×2×26 = 1,664 FF | |
| 收尾（E1/E2/E3） | 32×(27b 加 + 32b 加 + 移位/饱和) ≈ 3.0–3.5k LUT；~3.5k FF | |
| bias | 64×32 = 2,048 FF + 2:1 mux ≈ 0.3k LUT | |
| 输出队列 | 4 块 × 4 组 × (32+64) bit = 1,536 FF | |
| **LUT 合计** | **≈ 7–8k**（DSP 映射时） | 红线 12,000 ✅（**存疑**，未综合） |
| **BRAM18** | **0**（权重/输入都走分布式） | 红线 30 ✅（前提同上） |
| **FF** | ≈ 12–13k | 契约未给 FF 红线 |
| **Fmax** | **未综合、未布线，不给数字** | 关键路径估计：LUTRAM 读→字节 mux→DSP 乘→26b 加，~6 ns 量级（**推定**） |

## 8. 已知限制（逐条 + 数据）

1. **覆盖范围（最重要）**：本版 `cin≤64、cout≤64`，只覆盖 **16/132 个 k=1 层**，
   占 k=1 实测时间 **1.446 s / 27.486 s = 5.3%**、MAC **3.8%**。
   - 这 16 层是 **(64,16)×12 + (48,16)×4**（`runs/prof20261023_grid/layers_model_final.json`）；
   - 网络里**没有 (64,64) 层**；任务书把它当"最常见形状"，实际按 MAC 是
     (224,64) 19.4%、(160,64) 10.6%、(208,48) 10.3%、(256,96) 6.3%；
   - 扩展路径（未做）：`CIN_MAX=352` ⇒ 每 lane 权重 2×44 个 64-bit 字、
     像素缓冲 352 B×4；`COUT_MAX=192` ⇒ 6 个 32-lane bank。资源会线性涨，
     且 30 BRAM 红线更紧，需要重新评估（**不要**把本版资源直接外推）。
2. **cin 必须是 8 的倍数**：权重按 `cin/8` 个 64-bit 字整读；非 8 倍数会跨 oc 边界。
   全网络 132 个 k=1 层已核对，cin 全是 8 的倍数；但这不是架构保证。
3. **cin ≥ 8**：收尾 3 拍与下一块重叠要求块长 > 3；更短的层未实现。
4. **RELU 编译期**：`RELU=1` 默认；线性 k=1 层需要 `RELU=0` 重新综合一版。
   契约的 `ctrl_*` 没有 relu 位，本版不擅自加端口。
5. **cout 尾块**：`cout` 不是 8 的倍数时，最后一个 oc 组的尾部 lane 写 0
   （符合契约"PS 侧不读"），`cout_pad` 之外不写（不会越界）。
6. **写回粒度**：每个 oc 组 8 字节、AWLEN=0；320×320 层共 819,200 笔写、
   6.55 MB，按 ~4 拍/笔排空，摊到 13.1M 拍计算里约 25% 的写通道占用
   （与计算重叠）。若将来 cin 很小（≤16）而 cout 大，单笔写可能成为瓶颈，
   建议改成"8 像素 × 一组 = 64 B 的 burst"（未做）。
7. **没有综合/时序数据**：DSP 数量、BRAM 归属、Fmax 都是估算，不能当验收数据。
8. **PAD/STRIDE/DIL 无运行期寄存器**：k=1 恒 0/1/1；契约 §3 的这两个字段在
   k=1 上没有语义，本版不接。

---

## 9. 存疑 / 待主控确认

1. **xsim 实测拍数**：实测 **82,272**（第一轮），比 81,920 的纯计算下界只多
   352 拍（0.43%），说明输入 fetch/权重装载/写排空基本全藏住了；
   `ST_NEXT`/排空开销比预估的 450 还小。
2. **资源估算口径**：权重 RAM 是否被综合成 LUTRAM（`ram_style` 属性在
   `--sv` 下被 Vivado 接受，但**未跑 synth**）；若变成 32 个 BRAM18，会顶破
   §3.1 的 30 块红线。这是本版最大的综合风险。
3. **HLS 基线 531,437 的分账**：本版 82.4k 是"结构值 + 少量开销"，没有仿真分账；
   与 HLS 的差值里"权重 237 MB 重装"占多少是**推定**（按 `03_weight_path` 的
   逐层字节 × 2.76 拍/字节模型），未用 cosim 计数验证。
4. **`targets.tsv` 的 531,437** 是 HLS cosim 基线（含填充/写回/DDR），不是同口径
   的"计算"目标；0.155 的比值只说明本模块在这个形状上明显更快，不能直接外推到
   全网 27.49 s（覆盖范围只有 5.3%，见 §8.1）。

## 10. 与契约的偏差清单

| 项 | 偏差 | 理由 |
|---|---|---|
| 运行期形状 | 实现为运行期 `ctrl_cin/cout/h/w`（契约 §3 本来就允许），编译期参数是上界 | 为了能直接用 H=2 的黄金向量、也为将来 PS 按层选 IP |
| RELU | 编译期参数，无 `ctrl` 位 | 契约端口里没有 relu；不擅自加端口 |
| 输出写 | 单拍 8 B（AWLEN=0），不是 burst | 第一版优先正确性；带宽已与计算重叠，见 §8.6 |
| 权重读 | 只支持 `cin%8==0` | 64-bit 整字装 + 32 lane 同拍读；全网络 k=1 层满足 |
| 未做 | 综合、上板、git commit | 任务书明确不做 |
