# v60 总验收清单（一次上板跑完，分项判定）

> 适用：一次性综合位流 v60（扫描器全套 + RTL 数值三修 + slope_shift=12 + 三时钟域解耦）。
> **顺序不可换**：V-A → V-B → V-C → V-D → V-E → V-F。每项独立判据，**失败即停并报**，
> 不允许"跳过某步继续跑"，否则失败无法归因。

---

## 0. 上板前置（缺一项不开跑）

```sh
md5sum /home/xilinx/demo/design_1_v58.bit /home/xilinx/demo/design_1_v58.hwh   # 与交付 md5 逐字相同
sha1sum /lib/firmware/design_1_v58.bin                                         # byte-swapped bin
cat /sys/class/fpga_manager/fpga0/state                                        # operating 才允许碰 0x400A0000
```

改位流顺序（唯一允许）：**`stop` → 重载位流 → `start`**
（`reload → restart` 会因 restart 的 SIGTERM 写 `0x15`、紧接着 bringup 的 `0x01` 变成**第二次武装** ⇒ FSM 死）

---

## V-A 位流与时钟（阻断级）

| 判据 | 阈值 |
|---|---|
| `state` | `operating` |
| `FCLK0` | 报 **SLCR 原文 + DIV0+1 + 真值**，真值 50.79 或 66.67（按本项要求的档） |
| `FCLK1` | 同上（`0xF8000180`，DIV1 = bits[13:8]） |
| pix 心跳 | `0x30[0]` 在 200 ms 窗口内翻转，≈74.2 MHz（±3%） |
| `init_done` | `0x04[0] = 1` |

失败处置：任何一项不符 ⇒ 停，报 `state`/SLCR 原文，**不进 V-B**。

---

## V-B 共存：50.79 MHz 下扫描器可用（阻断级）

| 判据 | 阈值 |
|---|---|
| `0x2C` 增量（静置 60 s） | **0**（≤1 行/万行） |
| `0x24` | 每帧 +1，100 帧连续推进 |
| `nonblack` | ≥ 88%（逐帧，100 帧最小二值） |
| `CTRL` | `0x01` |

```sh
systemctl stop demo-player; echo design_1_v58.bin > /sys/class/fpga_manager/fpga0/firmware
systemctl start demo-player          # 或手工：feed_display.py --mode play
printf 'START\n' | nc -q1 192.168.7.2 9999     # ⛔ 不要 STOP
```
失败处置：`0x2C` 涨 ⇒ 停（这是本轮要修的那个 bug 没修好）⇒ 报增量速率（行/秒）。

---

## V-C 重新武装：不再需要重载位流（阻断级）

**目的**：`cfg_req` 重武装修好后，`CTRL 0→1` 可以**在同一 PL 上做第二次**。

| 判据 | 阈值 |
|---|---|
| 第 1 次 `0x01` 后 | `0x2C` 增量 0、`0x24` 推进 |
| 写 `CTRL=0x00`（等效掉使能）→ 再写 `0x01` | 第 2 次仍出图、`0x2C` **仍为 0**、`0x24` 继续推进 |
| 重复第 3 次 | 同上（允许做到 3 次以确认不是"第二次侥幸"） |

失败处置：第 2 次黑屏或 `0x2C` 起涨 ⇒ **V-C 失败**（本轮核心目标未达成），停；
不要把"重载位流后能出图"当成通过。

## V-D 数值：5 张冻结样本（阻断级）

```sh
cd /home/xilinx/demoir/ps/pynq
env XILINX_XRT=/usr BV_FREE=1 python3 board_verify_numfix.py \
    --pack /home/xilinx/demoir/deploy/bin_weights_new \
    --input /home/xilinx/demo/frozen256/p0000_crop256.npy \
    --golden /home/xilinx/demo/frozen256/golden/p0000_out1_fp.npy \
    --json /home/xilinx/demo/numfix_p0000.json
```

| 门 | 阈值 |
|---|---|
| A1' `mean|Δu8|` | ≤ 16 |
| A2' PSNR | ≥ 20 dB |
| A3' `|Δmean|` | ≤ 0.05 |
| A4' `corr` | ≥ 0.80（仅当 `ref_std ≥ 0.06`） |
| A5' `σ(i8)/σ(ref)` | ∈ [0.60, 1.40] |
| A8' `in_sha1` | 必须 = golden 侧记录值（**先验输入一致再谈数值**） |

5 张全过才算过。任一张不过 ⇒ 报该张的门值明细，停。
**基线对照（修复前，50.79 MHz）**：`max|Δu8| 129~219`、`rel_rms 0.38~0.58`、`corr 0.35/0.26/−0.07/−0.24/0.25`。

## V-E 时钟解耦：扫 FCLK1 不动数值（阻断级）

**固定** `FCLK0`（计算域），**只扫** `FCLK1`（扫描域）。

| `FCLK1` 目标真值 | 实际可达 | 做法 |
|---|---|---|
| 66.67 | **66.67**（DIV1+1=16） | `Clocks.fclk1_mhz = 100` |
| 100 | **96.97**（DIV1+1=11，±3% 误差） | `Clocks.fclk1_mhz = 150` |
| 133.33 | **133.33**（DIV1+1=8） | `Clocks.fclk1_mhz = 200` |

> ⚠ `f_pll = 1066.67` ⇒ 100 MHz **不可精确表示**（1066.67/10=106.67、/11=96.97）。
> 每档都按 **SLCR 原文 + DIV1+1 + 算出的真值** 记录，不写"150"这种报数。

| 判据 | 阈值 |
|---|---|
| 扫描器三档全绿 | `0x2C` 增量 0、`nonblack ≥ 88%`、`0x24` 推进 |
| 整网 sha1 | 三档**完全相同**（时钟解耦的直接证据） |
| 整网耗时 | 三档**不变**（±2%，只允许 FCLK1 抖动） |

失败处置：某档 `0x2C` 起涨 ⇒ 该档扫描域不适配，报档位；sha1 随 FCLK1 变化 ⇒ **解耦失败（严重）**。

## V-F 性能三条件（观察级，不阻断）

同 `V-B` 的位流状态，按 `runs/opt_round1/perf/Q1_report.md` 的方法：

| 条件 | 扫描器 | 期望 |
|---|---|---|
| C1 | 关（`CTRL=0x15`） | 纯计算基线 |
| C2 | 开 + 真播（`0x24` 推进） | 相对 C1 的**真实代价** |
| C2c | 内部彩条（`CTRL=0x14`，零 DDR 读） | ≈ C1（已验证：+1.0%） |

每条件 3 进程 × 2 跑（第 2 跑算数），必须 `BV_FREE=1`（否则第 2 跑 OOM）。
记录 `warm/steady/中位数` + `0x2C` 增量 + 真值频率。

**修复前基线（50.79 MHz，扫描器关）**：steady **10.28 s**（C1）、**10.38 s**（C2c）。
