## 1. 项目目标与约束

- **目标**：在 AMD Zynq-7000 系列 SoC（PS+PL）上部署图像去摩尔纹（demoiréing）算法
- **约束**（用户已明确）：
  - 单张图片推理即可，**不需要实时视频**（秒级延迟可接受）
  - 画幅可大幅降低：720p、600×400 均可，更小也行
  - 优先级：小参数量 > FPGA 实现友好 > 极致画质

### ⚠️ 未决问题（接手后第一件事：向用户确认）
1. **输入源**是相机拍屏幕还是已有图片库？若是相机，其输出分辨率是多少？
   （关键原因：摩尔纹频率与采集分辨率绑定。**不能把 4K 图降采样后训练/推理**——摩尔纹会混叠变形。采集分辨率 = 训练分辨率 = 部署分辨率）
2. 具体芯片型号（Z-7010/7020/7045/7100？）及板卡（资源差异大：Z-7020 为 220 DSP / 4.9Mb BRAM）
3. 新训练机器的 GPU 型号/显存（决定 batch size；代码默认双卡）
4. 是否有科学上网（下载数据集需访问 Google Drive）

## 2. 技术路线（已定，勿推翻重来）

```
PDNet (1.56M 参数，现成代码+蒸馏训练流程)
  → 在目标小画幅上重训 + 可选继续砍通道 (~0.5M)
  → INT8 量化（借鉴 QuantDemoire 的激活离群值处理思路）
  → Vitis HLS 数据流部署到 Zynq-7000
```

- 二值化（BinaryDemoire 路线）已**降级为可选优化**：600×400 下 INT8 计算量仅 GOPs 级，220 个 DSP 够用，不必冒 STE 二值训练的风险
- 曾考虑过的路线及否决理由见第 6 节

## 4. PDNet 代码分析（下一个 agent 必读）

### 4.1 网络结构（`model/nets_student.py`）

ESDNet 骨干 + 三个轻量化改造：

| ESDNet 原模块 | PDNet 替换为 | 效果 |
|---|---|---|
| RDB（密集膨胀卷积块） | **GhostModule**：`primary_conv`(1×1) 出一半通道 + `cheap_operation`(3×3 dilated) 生成另一半，拼接 | 参数约减半 |
| SAM 内的 DB | GhostModule1（无残差版） | 同上 |
| CSAF（SE 注意力融合） | **ECA**：1D conv(k=9) + ChannelShuffle，无降维升维 | 极轻量 |

- 整体拓扑与 ESDNet 相同：pixel_unshuffle×2 → 3 级编码器(48/96/192ch) → 3 级解码器(64ch) → pixel_shuffle×2
- `my_model.forward` 返回 `out_1, out_2, out_3, feature_map`（5 个中间特征，供蒸馏用）
- SAM 仍是三分支（1×/0.5×/0.25× 双线性插值）结构

### 4.2 蒸馏机制（`model/nets_teacher.py` + `utils/loss_util.py`）

- **Teacher 不是原版 ESDNet**，是作者自训的 Ghost 放大版（`T_en_i=48` vs student 32），checkpoint 名 `ghost_34large`
- 损失 = 多尺度(1×/0.5×/0.25×) L1 + VGG perceptual + **自适应小波蒸馏**：对 5 对中间特征做 DWT 后 L1，权重系数 40，且**仅当 student 的 L1 比 teacher 差时才计入**（`l1_s > l1_t` 判断，loss_util.py:31-42）
- DWT 实现在 `utils/loss_util.py` 的 `DWT` 类（Haar，仅训练期用）

### 4.3 训练配置（`config/uhdm_config_distillation.yaml`）

- batch 2、crop 768、150 epochs、Adam lr 2e-4、CosineAnnealingWarmRestarts(T_0=50, T_mult=1)
- Teacher 权重路径：`./Teacher_checkpoint/ghost_34large/UHDM/checkpoint_000150.tar`

## 5. 下一步行动清单（按序执行）

### Phase 0：环境与数据（新机器上）

   （torch 需按目标显卡架构单独装，命令见 `docs/训练/流程_双机协作.md` 3.2）
2. 下 UHDM 数据集：`bash scripts/download_data.sh`（或手动 gdown，ID 见脚本）
   → 或用 `python tools/download_uhdm.py`（支持断点续传；配额被打满时走文件夹链接）
3. 下 teacher 权重（百度网盘链接见 README），放到 `T_load_path` 指定位置
4. 改 config 数据路径；改 `train.py` GPU 硬编码适配新机器
5. **冒烟测试**：把 EPOCHS 临时改小，跑通若干 iteration，确认数据管线/蒸馏 loss 正常

### Phase 1：基线复现训练
- 按原配置完整训练（单卡 3090 级别预计数天）
- 验证指标：UHDM 测试集 PSNR（论文宣称用 26% 参数达到与 ESDNet 可比性能；具体数值以复现为准）

### Phase 2：小画幅适配（对应用户的 600×400 需求）
- `CROP_SIZE` 改为部署画幅（如 384 或 448，保持 32 倍数）
- **先和用户确认输入源**（见第 1 节）再定数据策略：
  - 相机采集 → 用目标分辨率重新采集/合成数据
  - 已有图片 → 直接按目标画幅 crop（不要 resize 降采样）
- 可选：EN_FEATURE_NUM 48→32、EN_INTER_NUM 32→16 继续砍参数，并用 Phase 1 模型当新 teacher 做二次蒸馏

### Phase 3：量化与 FPGA 部署
- INT8 QAT/PTQ。**注意 QuantDemoire 论文（arXiv 2510.04066）的结论：摩尔纹模型激活分布有离群值，直接套通用量化会掉点**，需分通道 clipping 或少量 FP16 混合
- HLS 算子清单（按难度）：
  - 常规 3×3/1×1 卷积阵列（ghost block 就是 1×1 + 3×3 dilated，两个核可合并调度）
  - 双线性插值（SAM 的 0.5×/0.25× 分支）、pixel shuffle/unshuffle（纯布线）
  - ECA（1D conv k=9 + channel shuffle）
  - dilated conv 行缓冲寻址（dilation 1/2/3）
- 单张图、小画幅下不需要 tiling，特征图可流式过 PL；权重 ~1.5M×8bit ≈ 1.5MB，需挂 DDR 或分批加载（612KB BRAM 放不下全部，砍到 0.5M 后 INT8 ≈ 0.5MB 仍超，需规划）

## 6. 调研结论存档（避免重复调研）

### 已否决的路线
| 路线 | 否决理由 |
|---|---|
| BinaryDemoire 二值化复现（0.31M/0.78G，UHDM 20.97dB） | 官方仓库**空**（仅 README+图，2026-02-04 push，TODO 未勾）；小画幅下 INT8 算力够，不值得冒 STE 训练风险。若二期要极限压缩可 revisit（公式都在论文 md 里：MABG=Alg.1+式4-7，SGRA=式8-9） |
| MopNet（ICCV 2019，58M） | 无官方代码；non-local block 是 O(N²)，FPGA 杀手。仅借鉴：RGB 通道不均衡现象（Bayer CFA R/B 采样率是 G 一半）、Sobel 辅助监督（训练期用，部署零开销） |
| Freqformer / ESwinDNet / MZNet | Transformer/大核+注意力，FPGA 不友好 |
| 剪枝原版 ESDNet | PDNet 已做了同类工作且更系统（蒸馏+ghost），没必要重复 |

### 作者关系图谱（找后续代码/更新用）

### 指标基线（UHDM 数据集，PSNR）
- ESDNet（全精度 5.93M/17.59G）：22.12 dB ← 质量上限参考
- BinaryDemoire（0.31M/0.78G）：20.97 dB
- PDNet（~1.56M/~5.2G）：论文称与 SOTA 可比，复现值待定

### Zynq-7000 关键资源（Z-7020 参考值）
- 220 × DSP48E1（INT8 约 44 GMAC/s @200MHz）
- 4.9Mb（≈612KB）BRAM
- DDR 带宽约 2.4 GB/s（32-bit）
- LUT ~53K（这是选轻量化路线的本钱：算子尽量往 LUT 搬）
