## 1. 拓扑

```
        MaixCAM Pro                        AX7015B
  ┌──────────────────┐            ┌────────────────────────────┐
  │ 10.13.148.1/24   │            │  10.13.148.100/24          │
  │ (NCM)            │  USB 2.0   │  on usb1 (cdc_ncm)         │
  │ 10.13.149.1/24   │◄──────────►│  usb0 (rndis_host) 已压下  │
  │ (RNDIS)          │  480 Mbps  │                            │
  └──────────────────┘            │  PS USB0 ── USB3320C(ULPI) │
         │                        │      │                     │
         │                        │      └─ 板载 hub 0424:2514 │
         └────── 插在 hub 任一 Type-A 口 ─────┘                │
                                  └────────────────────────────┘
```

$$\Rightarrow\ \text{一条 USB 线走两条网络通道（NCM + RNDIS）} \Rightarrow \textbf{只用 NCM 那条}$$
$$\Rightarrow\ \text{RNDIS 必须压下，否则两条通道抢默认路由}$$

## 2. 接口名陷阱（最容易踩）

$$\Rightarrow\ \textbf{NCM 被内核注册成 } \texttt{usb1}，\textbf{RNDIS 才是 } \texttt{usb0}$$
$$\Rightarrow\ \text{旧文档写的"板端 } \texttt{usb0}\ \text{用 } 10.13.148.100\text{"是错的} \Rightarrow \text{按它写脚本会直接失败}$$
$$\Rightarrow\ \textbf{而且接口名可能随 probe 顺序变}（\texttt{usb0}/\texttt{usb1}\ \text{不保证）} \Rightarrow \textbf{不要硬编码}$$

**按驱动查找（推荐写法）：**
```sh
IF=$(for d in /sys/class/net/usb*; do
       [ -e "$d" ] || continue
       [ "$(readlink -f "$d/device/driver")" = "$(readlink -f /sys/bus/usb/drivers/cdc_ncm)" ] \
         && basename "$d"
     done)
echo "NCM 接口 = $IF"
```

**两个易误判点：**
1. **网卡 DOWN 时 `/sys/class/net/*/carrier` 读出 `Invalid argument`，不是 `0`** ⇒ 必须先 `up` 再读。
2. `/sys/class/gpio/` 里**看不到**被 `gpio-hog` 占用的引脚（MIO8）⇒ `export 520` 会报 `Device or resource busy`，这是**正常且是 hog 生效的证据**。

## 3. 手动配通（现场调试用）

```sh
# ① 关掉 RNDIS 那条，避免双通道抢路由
ip link set usb0 down 2>/dev/null
ip addr flush dev usb0 2>/dev/null

# ② 拉起 NCM 并配静态地址
ip link set usb1 up
ip addr flush dev usb1 2>/dev/null
ip addr add 10.13.148.100/24 dev usb1

# ③ 验
cat /sys/class/net/usb1/carrier          # 期望 1
ping -c 5 -W 2 10.13.148.1               # 期望 5/5，0% 丢包
ip neigh show dev usb1                   # 期望 10.13.148.1 REACHABLE
```

$$\Rightarrow\ \text{以上命令需要 root}（\texttt{sudo}）\Rightarrow \text{板端 } \texttt{xilinx}\ \text{用户密码 } \texttt{xilinx}$$
$$\Rightarrow\ \text{板端镜像}\textbf{没有 } \texttt{udhcpc}\ \text{，只有 } \texttt{/usr/sbin/dhclient}$$

**相机会自己发 DHCP（备用方案）：**
```sh
sudo dhclient -1 usb1     # 相机上跑着 udhcpd(67)，会给你 10.13.148.100
```
$$\Rightarrow\ \text{DHCP 与静态给的是同一个地址} \Rightarrow \text{所以静态没有竞争风险}$$

## 4. 开机自动化（已在板上落地，冷启动 2/2 验证通过）

### 4.1 服务文件
`/etc/systemd/system/usb-cam-net.service`
```ini
[Unit]
Description=MaixCAM USB-NCM network setup
After=network.target

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/sbin/usb-cam-net.sh

[Install]
WantedBy=multi-user.target
```

### 4.2 脚本 `/usr/local/sbin/usb-cam-net.sh`
```sh
#!/bin/sh
# MaixCAM USB-NCM 链路自动配置
# 接口名不稳定（NCM 可能被注册成 usb0 或 usb1），按驱动 cdc_ncm 查找
i=0
while [ $i -lt 30 ]; do
    for d in /sys/class/net/usb*; do
        [ -e "$d" ] || continue
        drv=$(readlink -f "$d/device/driver" 2>/dev/null)
        [ "$drv" = "$(readlink -f /sys/bus/usb/drivers/cdc_ncm 2>/dev/null)" ] && break 2
    done
    i=$((i+1)); sleep 1
done
IF=""
for d in /sys/class/net/usb*; do
    [ -e "$d" ] || continue
    drv=$(readlink -f "$d/device/driver" 2>/dev/null)
    if [ "$drv" = "$(readlink -f /sys/bus/usb/drivers/cdc_ncm 2>/dev/null)" ]; then IF=$(basename "$d"); fi
done
[ -z "$IF" ] && { echo "usb-cam-net: cdc_ncm 接口未出现，退出"; exit 1; }
for d in /sys/class/net/usb*; do
    [ -e "$d" ] || continue
    r=$(readlink -f "$d/device/driver" 2>/dev/null)
    if [ "$r" = "$(readlink -f /sys/bus/usb/drivers/rndis_host 2>/dev/null)" ]; then
        ip link set "$(basename "$d")" down 2>/dev/null
        ip addr flush dev "$(basename "$d")" 2>/dev/null
    fi
done
ip link set "$IF" up
ip addr flush dev "$IF" 2>/dev/null
ip addr add 10.13.148.100/24 dev "$IF"
echo "usb-cam-net: $IF -> 10.13.148.100/24"
```

### 4.3 状态检查
```sh
systemctl is-enabled usb-cam-net.service   # enabled
systemctl is-active  usb-cam-net.service   # active
journalctl -u usb-cam-net -n 20 --no-pager # 应看到 "usb-cam-net: usb1 -> 10.13.148.100/24"
```

## 7. 故障对照表

| 现象 | 先查 | 说明 |
|---|---|---|
| `lsusb` 里没有 hub/相机 | 板上 `MIO8`（`OTG_RESETN`）是否被 hog 拉高 | 见 `02` 文档 §13；`export 520` 报 `Device or resource busy` = 正常 |
| `usb1` 不存在但 `usb0` 在 | 是不是只有 RNDIS 起来了 | 检查 `dmesg \| grep cdc_ncm` |
| `carrier` 读报 `Invalid argument` | 网卡是不是 DOWN | **先 `ip link set usb1 up`** |
| `ping` 不通但 RX 有增长 | IP 段/接口选错 | 确认用的是 **NCM（`usb1`）** 而不是 RNDIS |
| `ping` 不通且 RX 恒 0 | 链路层没通 | 查 `dmesg` 有无 `usb 1-1.2`，查 hub 是否枚举 |
| `8660` 连不上 | 相机侧 app 是否部署 | **当前未部署**，不是故障 |
| ssh 相机失败 | 密码/端口 | `root`/`root`，端口 22 |
