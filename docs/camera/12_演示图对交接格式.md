# 演示图对交接格式（给做图/算法的同事）

> 目的：把你们的"原图 / 处理结果"做成板端 HDMI 演示能直接用的格式。
> **你们只管给图，转换由我们一条命令完成**，不需要你们关心 640×640、RGB888、字节序这些东西。

---

## 1. 我们要什么

**成对**的两张图，**同一场景、同一裁切**：

| | 内容 |
|---|---|
| 左半（原图） | 带摩尔纹的原始拍摄/截图 |
| 右半（结果） | 你们方法处理后的结果，**与左边逐像素对齐**（同机位、同缩放、同裁切） |

- 对齐是硬要求：演示是左右并排，错开一眼就看出来

## 2. 数量

- **8~16 对**（8 对 ≈ 8 s 一轮，播放时每对停 1 s）
- **前两张建议是"文字/表格底"**（摩尔纹在文字上最直观，观众一眼能看懂对比）
- 其余可以是照片、屏幕翻拍等，但要**能看出摩尔纹**

## 3. 文件格式

| 项 | 要求 |
|---|---|
| 扩展名 | `.jpg` / `.png` / `.bmp` / `.tif` |
| 位深 | **8 位/通道**（不要 16 位） |
| 颜色 | **RGB**（不要 CMYK，**不要带 alpha 通道**） |
| 尺寸 | **任意**，建议 ≥ 640×640；太小放大后发虚 |
| 左右尺寸 | 两张**宽高比必须一致**（分辨率可以不同，比如 4032×3024 与 1920×1440 都行） |
| 画质 | jpg 用 `quality ≥ 90`；能无损就无损（png/tif） |

**不要**：水印、标注、箭头、放大镜、边框、拼图。**我们要纯净画面**（画面上一个字都不要有）。
**不要**：尺寸不一致或宽高比不一致的两张（中心方裁会导致内容错位，工具会直接报错）。

## 4. 命名（两种方式任选）

### 方式 A：按文件名成对（推荐）

```
0094_moire.jpg    0094_out.jpg
0049_moire.jpg    0049_out.jpg
...
```

- 左半后缀：`moire` 或 `in`
- 右半后缀：`out` / `proc` / `res` / `pred` / `gt`（任一）
- `NNNN` 随便叫什么（`0094`、`scene01`、`paper_A` 都行），**左右必须同名**

### 方式 B：给一个清单（命名完全自由时用）

`pairs.txt`，一行一对，空格分隔两个路径（相对该文件的路径也行）：

```
# 左 右
imgs/scene01_before.png   imgs/scene01_after.png
imgs/scene02_before.png   imgs/scene02_after.png
```

### 方式 C：直接给"排好版的整幅对比图"（左|右 拼在一起的 1280×720）

一张 `.png/.jpg`，宽高比 16:9，左半是原图、右半是结果。我们也支持（`--mode frames`）。

## 5. 交付

把一个**目录**（或 `pairs.txt`）发给我们即可。我们这边执行：

```bash
# 方式 A / B
python3 tools/prepare_demo_pairs.py --mode external --src <目录> --out runs/demo_pairs_external
python3 tools/prepare_demo_pairs.py --mode external --src <目录> --pairs-list pairs.txt --out ...

# 方式 C
python3 tools/prepare_demo_pairs.py --mode frames --src <整幅图目录> --out runs/demo_pairs_frames
```

产物：`pairs/NNNN_left.bin`、`pairs/NNNN_right.bin`（640×640 RGB888）+ `manifest.json`
+ `compose_check_0000.png`（1280×720 预览，人眼复核用）。**我们不再叠加任何标注。**

## 6. 常见问题

| 问题 | 答复 |
|---|---|
| 尺寸必须是 640×640 吗？ | **不用**。任意尺寸，我们做中心方裁 + 双线性缩放到 640×640。 |
| 左右分辨率不同行不行？ | **行**，但**宽高比要一致**（否则裁切会错位，工具会报错）。 |
| 可以带水印/图注吗？ | **不行**。演示画面要纯净。 |
| 可以给一整个拼好的对比图吗？ | **可以**，用方式 C。 |
| 图对能不能超过 16 对？ | 能，但演示一轮的时间会变长；建议 8~16。 |
| 需要你们标 PSNR 吗？ | 不需要。这是**演示**素材，不是评测数据。 |
