**期望**：`bin_net.py` = `0990948de490eb6ba6d4aaefbcafa355`，`bin_engine.py` = `2fd3d0990c47151fe3bc06544b8adb64`；后两行（`cam_client.py`/`demo_pipeline.py`）**只记录**进报告。

**失败先查**：`rsync` 用 `-a`，**不加 `--delete`**（会删掉板上已编译的 `.so` 内核）；`.bit` 与 `.hwh` 必须同名同目录成对。

### A2 载入 v58 + IP 清单 + 基址　**阻断级**
**前置**：A1 通过；板子空闲（一次只允许一个上板作业）。

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"

```

**期望**：清单含 `bin_unit_0`、`conv_uni_0` 与**至少一个**含 `hdmi` 的项；`bin_unit_0 0x40060000 131072`、`conv_uni_0 0x40040000 131072`。
**阈值**：三条都精确（基址来源：`runs/ACCEPT_v57/03_BITSTREAM/design_1_150v57.hwh`）。缺 `*hdmi*` ⇒ 位流是 v57，直接停。
**失败先查**：`.hwh` 没传或名字不配对 ⇒ `Overlay` 找不到硬件描述；基址第 16 位必须为 0，否则引擎的 `+0x10000` 配置页会翻到保留页、寄存器全读 0。

### A3 写 `fclk0_mhz = 75` 并读回　**阻断级**
**前置**：A2 通过。`Clocks` 需要 ZOCL 上下文 ⇒ **同一进程里先建 overlay**（契约 §8.4）。


**期望**：`target=75 readback= 75.0`
**阈值**：`abs(readback - 75) <= 0.5`。
**失败先查**：写 75 就是 75，**不要**套 HDMI 位流的"报数 = 真值 1.5 倍"口径（两 BD 的 IO PLL 不同）；`06_REPRODUCE §3.1` 的 `assert ==100` 已作废。报 `No device found` ⇒ overlay 没 load。

## B. 心跳与像素时钟（**B1 必须是第一次 PL AXI 访问**）

### B1 `0x30` 心跳：活性（阻断）+ 锁定（观察）
**前置**：A1~A3 通过。**本步之前不许读任何其它 PL 寄存器；一次只允许一个上板作业。**

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"
import sys
sys.path.insert(0, "/home/xilinx/demoir/ps/pynq")
from display_demo import DisplayPipeline
pipe = DisplayPipeline(mode=3)           # 故意不调 setup()：心跳先行（契约 §8.2）
alive, mhz = pipe.pix_alive(100)
print("alive=", alive, "rate_MHz=", round(mhz, 3), "mmcm_locked=", int(pipe.mmcm_locked()))
PY'
```

**期望**：`alive= True ... mmcm_locked= 1`（100 ms 内约 56 个沿，720p30 沿周期约 1.77 ms）。
**阈值**：**阻断**——`alive=True`（窗口内 ≥5 个翻转沿，`f_pix = edges * 65536 / dt`）；**观察**——`mmcm_locked`，契约 §8.5 规定它只许做状态上报、不进复位，`0` 不必然故障但必须记录。
**失败先查**：`alive=False` ⇒ **立刻停，不再读任何寄存器**。查板上 50 MHz 晶振（`Y14`）是否起振、MMCM 供电/复位、`VIDEO_MODE` 是否非法。

### B2 像素时钟（2 s 窗口）　**阻断级**
**前置**：B1 的活性通过。

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"

PY'
```

**期望**：`pix_MHz= 37.1xx`（2 s 窗口，精度约 ±0.09%）。
**阈值**：`36.74 <= mhz <= 37.48`（37.109 ±1%）。
**失败先查**：约 27.8 MHz ⇒ 像素 MMCM 仍由 75 MHz 的 FCLK0 驱动（位流不是 50 MHz 晶振版）；约 55.7 MHz ⇒ 按 150 MHz 输入设计；抖动大 ⇒ 窗口太短或 CPU 被占。

## C. 引擎数值

### C1 引擎复位指纹　**阻断级**
**前置**：A2/A3 通过（overlay 已 load）。


**期望**：`alpha_shift= 9 slope_shift= 8 ip= bin_unit_0`
**阈值**：`9` 与 `8` 精确相等（与 `board_v39_verify.step_identity` 同一条判据）；`ip_name` 必须是 `bin_unit_0`。
**失败先查**：指纹不对 ⇒ 位流或基址错（回 A2）；`ip_name` 不对 ⇒ `.hwh` 与位流不配对。

### C2 真实 sha1 三件套　**阻断级**
**前置**：C1 通过；权重包在 `/home/xilinx/demoir/deploy/bin_weights_new`。

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"
import sys, numpy as np
sys.path.insert(0, "/home/xilinx/demoir/ps/pynq")
from pynq import Overlay
import demo_pipeline as dp
ov = Overlay("/home/xilinx/demoir/runpoint.bit", download=False)
net, arena = dp.build_v57_net(ov, "/home/xilinx/demoir/deploy/bin_weights_new", 24)
x0 = np.random.default_rng(1).random((3, 256, 256), dtype=np.float32)
print("x0_sha1", dp.sha1_prefix(x0))
outs, st = net.run(x0, pipeline=True, nbuf=2, arena=arena)
print({k: dp.sha1_prefix(outs[k]) for k in ("out1", "out2", "out3")})
PY'
```

**期望**：`x0_sha1 cfc75bc3f15d`（**另一环境下可能是 `acdb772f481d`**，见阈值）；`out1 9b1940c8`、`out2 f86a7035`、`out3 025757a8`（前 12 位）。
**阈值**：**先判 `x0_sha1`**：`cfc75bc3f15d` = 与历史板端同环境 ⇒ 继续判三件套；`acdb772f481d` = 主机 numpy 2.2.6 那类环境（实测）⇒ **输入不同、三件套必然对不上** ⇒ 停下报**环境差异**，不许判网络错；其他值同理。**只有** x0 与历史一致时，三个前 12 位才必须逐字相等（`06_REPRODUCE §3.5`、`07_KNOWN_LIMITS §7`）。
**失败先查**：先看运行点 10 条（`BIN_PACK`/`Q8CACHE=1`/`BIN_LAZY_SLOTS=24`/…）与 A3 的 fclk，再对 A1 的 PS 代码 md5。**sha1 错不是显示器问题**，别去查 HDMI。

**期望**：`shape (256, 256, 3) uint8 md5 <32 位小写 hex>`

**失败先查**：`CamDisconnected` ⇒ 假相机没起来（看 `/home/xilinx/demoir/fc.log`）；`CamBusy` ⇒ 8660 被别的进程占着。

### D2 真相机取图　**阻断级**
**前置**：D1 通过；相机插板子 USB HOST 口，板侧 `usb0` 为 `10.13.148.100/24`。

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"
```

**失败先查**：`CamTimeout` ⇒ `usb0` 没有 `10.13.148.100/24`，或相机 app 没监听 8660；`CamBadJson` ⇒ 相机侧 app 不是协议 §3。

### D3 整链两轮 + 肉眼确认　**阻断级**（肉眼部分**观察级**）
**前置**：A3/B2/C2/D2 全部通过（这条会把它们串起来再跑一次）。

```bash
ssh xilinx@192.168.7.2 'cd /home/xilinx/demoir/ps/pynq && python3 demo_pipeline.py --runs 2 --json /home/xilinx/demoir/pipe_v58.json'
```

**期望**：两行 `[PIPE] stage` ＋ 一行 `[PIPE] done`：
```
[PIPE] frozen phase=verify x0_sha1=cfc75bc3f15d out1=9b1940c8 out2=f86a7035 out3=025757a8 gate=ok(frozen)
（若这里 `x0_sha1=acdb772f481d` ⇒ 环境不同，`gate` 会抛异常 —— 先按 C2 判环境，不是网络错）
[PIPE] runpoint phase=setup fake=0 mode=3 slots=24 fclk=75->75 pix=37.1xxMHz(design37.109) ps_md5=bin_engine=2fd3d099,bin_net=0990948d switches[10]=...Q8CACHE=1,... stray=-
[PIPE] stage capture=0.xxx compute=6.2xx compose=0.0xx display=0.0xx total=6.6xx s | frame_id=1 latched=1 | md5 orig=... proc=... frame=... | sha1_gate=n/a(live) out1=... | runpoint fake=0 switches=10 q8cache=1 slots=24 fclk=75->75 | 720p30 1280x720
[PIPE] done runs=2 total_min=6.5xx max=6.7xx s frame_id=2 sha1_gate=n/a(live)
```
**阈值（阻断）**：`[PIPE] frozen` 行 `gate=ok(frozen)` 且三个 sha1 对（这是**唯一**的数值门禁）；`q8cache=1`、`latched=1`、`frame_id` 依次 1、2；逐帧 `sha1_gate=n/a(live)` 是**正常**（真实帧无基准）。
**阈值（观察）**：`compute` 5.8~6.6 s；**首轮** `total` ≤13.5 s（含一次探针 ≈6.2 s）、后续 ≤7.0 s（对照 README 的 6.198~6.234 s，偏差 >10% 写进报告）；**肉眼**：左半原图、右半更平滑、上下各 40 px 黑边、无撕裂。
**失败先查**：`frozen` 行不是 `ok(frozen)` ⇒ 回 C2（含 numpy 版本）；抛 `PipelineError` ⇒ 回 B1；把 `/home/xilinx/demoir/pipe_v58.json` 原样带回主机存档。全黑但本步全绿 ⇒ 查显示器输入源与 `SIL9134` 链路；左右两半一样 ⇒ 引擎没生效（回 C2）。

### D4 换帧与欠载诊断　**观察级**
**前置**：D3 通过（此刻 PL 在持续扫描）。

```bash
ssh xilinx@192.168.7.2 'python3 - <<"PY"

```

**期望**：`underflow_cnt 0 -> 0`（或稳态不增长），`init_done=True`、`vsync=True`。
**阈值**：**间隔 2 帧两次读不增长**（契约 §8.14④：切模式那一帧允许计 1，稳态必须不涨）。
**失败先查**：持续增长 ⇒ 行内带宽不足（先确认模式是 720p30 而不是 1080p60）；`init_done=False` ⇒ SIL9134 的 I2C 没配完（契约 §6）。

## E. 本次**不验**（别声称验过）

| # | 不验的东西 | 为什么 | 什么时候能验 |
|---|---|---|---|
| 1 | **真实 ACLK 频率** | 像素时钟改由 50 MHz 晶振驱动、与 `FCLK0` 解耦；`0x30` 只反映晶振+MMCM 链，**不能反推 ACLK**。v59 候选 `0x34 ACLK_CNT`（契约 §8.19）尚未实现 | v59 位流 + `0x34` 就位后按 `f_aclk = dcount / dt` 测 |
| 2 | 相机裁剪正确性（`crop.center` == 全幅中心 256² 子块） | 需 PC 侧同时拿到全幅帧，属协议 §6 的 B 层判据 | 相机连着 PC 时按 `07_*.md` §6-B 验 |
| 3 | `SIL9134` 对 720p30 的规格确认、1080p60 带宽 | 芯片自适应只能看画面；合并方案 §1.1 已算 FCLK0 75 MHz 下 1080p60 不够（需 ≥445 MB/s） | D3 出图只算"能用"不算"厂规确认"；1080p60 不计划验 |
