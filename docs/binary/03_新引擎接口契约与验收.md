## 1. 定点契约（与 `gen_bin_golden.py` 逐位一致）

$$\text{二值化：}\quad b_i = [\,x_i + t_i > 0\,], \qquad w_i = [\,W_i > 0\,]$$

$$\text{内积：}\quad d = 2\cdot\mathrm{popcount}(b \oplus \overline{w}) - N_{\text{tot}}, \qquad N_{\text{tot}} = C_B \cdot 64 \cdot k^2$$

这里 `popcount(b XNOR w)` 就是 `popcount(~(b ^ w))`；`C_B = ceil(cin/64)`。

$$\text{外层：}\quad q = (d \cdot \alpha_q) \gg s_\alpha,\qquad q \mathrel{+}= \beta_q$$

$$\text{RPReLU：}\quad dd = q - \zeta,\quad r = \begin{cases} dd + \gamma & dd > 0 \\ ((dd \cdot \sigma) \gg s_\sigma) + \gamma & dd \le 0\end{cases}$$

$$\text{输出：}\quad y = \mathrm{sat}_{[-128,127]}(r \gg s)$$

参数位宽（golden 与硬件必须一致）：

| 参数 | 类型 | 每 oc 一个 | 说明 |
|---|---|---|---|
| `alpha_q` | int16 | ✓ | `alpha_shift = 9` |
| `bias_q` | int32 | ✓ | |
| `zeta` | int32 | ✓ | |
| `gamma` | int32 | ✓ | |
| `slope` | int16 | ✓ | `slope_shift = 8` |
| `shift` | 全局 | | 输出右移位数，来自 `meta.json` |

中间量一律 **int64**（`d·alpha_q` 最多 25×9=34 bit），右移是**算术右移**（负数向 −∞）。

### 1.1 补零通道的约定（**v2 已修正：以 golden 为准**）

`cin` 不是 64 的倍数时补零到 `C_B·64`。**权威约定（与 `gen_bin_golden.py` 的 `gen()` 逐位一致）**：

$$\text{补零通道不参与 popcount} \Rightarrow d = 2\cdot p_{\text{real}} - N_{\text{tot}},\qquad N_{\text{tot}} = C_B\cdot 64\cdot k^2$$

也就是说：`p` 只统计 `c < cin` 的真实通道（`gen()` 里 `if c >= cin: continue`），
但 `N_tot` **仍按补零后的总线数**计算。所以：

$$d = \left(\sum_{\text{真实抽头}} \pm 1\right) - n_{\text{pad}},\qquad n_{\text{pad}} = (C_B\cdot 64 - cin)\cdot k^2$$

这个 $-n_{\text{pad}}$ 是**每层固定的常数偏移**，会被逐 oc 的 `bias_q` 吸收，
不影响模型语义，但**硬件必须照此实现（有效位掩码）**，否则每个输出字节都会差一个常数。

> 本条是 v1 写错后的修正。v1 曾声称"补零位 XNOR 得 +1 且被 `N_tot` 抵消"，
> 那是错的：若补零位真按 +1 计入，则 $d = 2(p+n_{pad}) - N_{tot}$，与 golden 差 $2n_{pad}$。
> 实测反例：`cin=32` 的形状不做掩码会全字节错，且偏差是常数 $64\alpha_q\gg9$ 而非 $\pm2$。

## 2. `bin_conv_core` 端口契约（**一个字都不要改**）

```verilog
module bin_conv_core #(
    parameter int LANES    = 64,
    parameter int COUT_MAX = 192
)(
    input  logic        ap_clk, ap_rst_n,
    input  logic        ctrl_start,
    output logic        ctrl_done,      // 单拍脉冲即可
    output logic        ctrl_busy,
    input  logic [15:0] cfg_cin, cfg_cout, cfg_k, cfg_s, cfg_d, cfg_pad, cfg_h, cfg_w,
    input  logic [5:0]  cfg_alpha_shift, cfg_slope_shift, cfg_shift,
    input  logic [31:0] base_act, base_wgt, base_alpha, base_bias,
    input  logic [31:0] base_zeta, base_gamma, base_slope, base_out,
    output logic        mem_rd_en,
    output logic [31:0] mem_rd_addr,
    input  logic [63:0] mem_rd_data,    // rd_en 后**下一拍**有效（BRAM 语义）
    output logic        mem_wr_en,
    output logic [31:0] mem_wr_addr,
    output logic [7:0]  mem_wr_data     // 写当拍生效
);
```

### 2.1 内存映射（字节地址，均相对 `base_*`）

| 区域 | 地址 | 内容 |
|---|---|---|
| 激活 | `base_act + (b·H·W + y·W + x)·8` | 64-bit 字，第 i 位 = 通道 `b·64+i` 的二值值 |
| 权重 | `base_wgt + ((o·k·k + j)·C_B + b)·8` | 第 i 位 = `W[o][b·64+i][j]` 的二值值，`j = ky·k+kx` |
| `alpha_q` | `base_alpha + o·2` | int16 小端 |
| `bias_q` | `base_bias + o·4` | int32 |
| `zeta` | `base_zeta + o·4` | int32 |
| `gamma` | `base_gamma + o·4` | int32 |
| `slope` | `base_slope + o·2` | int16 |
| 输出 | `base_out + (o/8)·H_out·W_out·8 + y·H_out?→` 见下 | int8，C8 交错 |

输出地址（**与现有 k1/k3/k5 完全一致**，便于同一条流水线串起来）：

$$\mathrm{addr}(o,y,x) = \left\lfloor \frac{o}{8} \right\rfloor H_{out} W_{out} \cdot 8 + y\,W_{out}\cdot 8 + x \cdot 8 + (o \bmod 8)$$

## 4. 性能目标（不作为验收判据，但要往这做）

$$\text{64 lane，107.1 MHz} \Rightarrow \text{内层 } 6.85\ \text{G popcount/s}$$

参考拍数（`bin_1x64_16x16`）：`cout·H·W·C_B·k² = 64·8·8·1·1 = 4096` 拍。
桩是 2000 万拍上限，达到 `≤ 3×` 参考拍数即可视为性能合格。

## 5. 交给实现者的硬约束

1. **端口与内存映射一个字都不要改**（TB 与 golden 都按它生成）。
2. `mem_rd_en` 拉高后 `mem_rd_data` **下一拍**才有效；不要假设同拍。
3. 只允许单主内存口（一个读、一个写），不要自己加 AXI —— AXI 桥接是后续
   `bin_conv_core_axi_wrap` 的事，与内核解耦是刻意的。
4. 不要为了"快"改动定点语义。判据是**逐字节**，差一个 LSB 就是 FAIL。
5. 允许内部流水、允许乱序取数，但**输出必须逐字节正确**。

## 7. 集成层（`bin_unit_axi_wrap`）契约

四个单元的单主内存口完全同构，所以**只写一个通用 wrapper**，用参数选择嵌哪个单元，
不再写四份近似重复的代码。

### 7.1 寄存器映射（沿用 k1/k3/k5 的两页式，软件侧好统一）

配置页（`+0x10000`，128 KB 窗口）：

| 偏移 | 名字 | 说明 |
|---:|---|---|
| 0x00 | `AP_CTRL` | bit0 = start（写 1 启动），bit1 = auto-restart |
| 0x10 | `AP_RETURN` | 只读：bit0 = done，bit1 = busy，bit[15:8] = 错误码 |
| 0x18 | `R_C` | 通道数（`bin_conv_core` 用 `cin`）|
| 0x20 | `R_H` | 输入高 |
| 0x28 | `R_W` | 输入宽 |
| 0x30 | `R_HO` | 输出高（interp 用；其它单元忽略）|
| 0x38 | `R_WO` | 输出宽 |
| 0x40 | `R_K` / `R_S` / `R_D` / `R_PAD` | 卷积参数（`bin_conv_core` 用）|
| 0x60 | `R_SHIFT` | 输出右移 |
| 0x68 | `R_ALPHA_SHIFT` / `R_SLOPE_SHIFT` | 见 §1 |
| 0x80 | `B_IN`  | 输入基址 |
| 0x88 | `B_IN2` | 第二输入（`bin_sam` 的 y0）|
| 0x90 | `B_IN3` | 第三输入（y2）|
| 0x98 | `B_IN4` | 第四输入（y4）|
| 0xA0 | `B_WGT` | 权重基址（`bin_sam` 的 w0）|
| 0xA8 | `B_W2` / `B_W3` | 第二/三组权重（w2/w4）|
| 0xB0 | `B_BIAS` | 偏置基址 |
| 0xB8 | `B_ZETA` / `B_GAMMA` / `B_SLOPE` | RPReLU 三参数基址 |
| 0xD0 | `B_OUT` | 输出基址 |

（64-bit 基址用「低 32 位在偏移、高 32 位在 +4」的老规矩，与 k1 一致。）

### 7.2 内存侧

一个 AXI master（读 + 写），把单元的单内存口翻译成 AXI：
- 读：`mem_rd_en` → `arvalid`（`arlen=0` 单拍即够，因为单元一次只取一个 64-bit 字）；
  **必须支持多笔在飞**（否则会重犯 k1 当年每笔 56 拍的错，见 `上板性能优化_20261028.md`）
- 写：`mem_wr_en/mem_wr_addr/mem_wr_data` → 打包成 burst 再发。单元写口是 8-bit、
  地址在 C8 布局下**连续像素恒 +8**，所以能攒成 8 拍（=64 bit/beat）的 burst。

### 7.3 两条**必须在集成层强制**的约束

1. **`bin_sam` 的三组权重基址必须 8 字节对齐**（它按对齐 64-bit 字读 int16）。
   权重打包时要补对齐，或在 wrapper 里检查并报错误码。
2. **`C` 必须是 8 的倍数**（`bin_rprelu/sam/interp` 都按 8 通道一组遍历 C8）。
   二值网实际的通道数（32/48/64/96/…/544）全部满足，但**要在 wrapper 里做一次断言**，
   免得将来换了形状才在下板上暴露。
