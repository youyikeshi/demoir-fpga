## 1. 两条主线

这个项目有两条互不相干的线。**先确定你在哪条线上，再进对应的入口。**

```text
训练/  ──产出权重──▶  weights/  ──作为输入──▶  部署/
模型怎么训出来          权重                   模型怎么落到 AX7015B 上
```

| 线 | 入口 | 一句话 |
|---|---|---|
| **部署**（上板） | **[`部署/README.md`](部署/README.md)** | 把训练好的权重变成能在开发板上跑的东西。当前卡在"需要接板子" |
| **训练**（模型） | **[`训练/交接文档_去摩尔纹训练部署.md`](训练/交接文档_去摩尔纹训练部署.md)** | 训练、评估、分块推理、双机协作、数据集 |
| 仓库约定 | [`仓库/规范_目录结构.md`](仓库/规范_目录结构.md) | 仓库怎么分区的、从旧结构怎么迁过来的 |
| **写文档** | **[`仓库/规范_文档编写.md`](仓库/规范_文档编写.md)** | 信息架构（入口/指针/层次）、文件命名、图怎么画 |
| 教学材料 | [`tutorial/README.md`](tutorial/README.md) | 零基础讲解，只讲原理不带操作 |
