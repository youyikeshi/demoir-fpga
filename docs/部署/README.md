# 部署 —— AX7015B 上板这条线

> 这条线分**两段**，互不重叠：
>
> ```text
> ① 把板子跑起来    XSA ──▶ PetaLinux 镜像 ──▶ PYNQ SD 镜像 ──▶ 上板验收
>                    └── ✅ 已上板实测通过（2026-10-06）        ← 本文指路
>
> ② 把模型放上去    切分 ──▶ 量化 ──▶ HLS 加速器 ──▶ PS 调度 ──▶ 相机接入
>                    └── M0 完成 + M2 的算子与综合已跑通；量化(M1)未开始
> ```
>
> **当前进度（2026-10-06）**：① **已上板实测通过** —— 板子从 SD 卡正常启动、串口可用、
> 网口通（100Mb/s Full）、根分区已扩到 28.6 GB、`import pynq` 成功、`pyxrt.device(0)` 打开成功、
> `/dev/dri/renderD*` 在。验收结果 **12 通过 / 2 警告 / 1 失败** ——
> 唯一的失败是 `pynq.allocate`，它必须先加载一个 overlay，属于**设计如此**，等 M2 的第一个 overlay。
> **② 的软件侧已经开工**：算子切分已定、HLS C++ 算子写完并通过三段等价性验证，
> 见 [`../../hls/README.md`](../../hls/README.md)。

## 3. 能跑的东西在 `deploy/`

本文只讲**为什么**和**怎么做**；脚本、配方、补丁、设备树片段都在
[`../../deploy/`](../../deploy/)，入口 [`../../deploy/README.md`](../../deploy/README.md)。

```text
deploy/
├── env.sh                       ← 唯一的构建根定义（换路径只改它）
├── peta/                        ← PetaLinux 侧
│   ├── create_peta_project.sh   建工程 + 导入 XSA + 配置 + 设备树 + zocl 配方
│   ├── build_peta.sh            构建 + zocl + 重打 BOOT.BIN + 验证
│   └── files/system-user.dtsi   设备树补充的权威文件（带逐条注释）
├── pynq/                        ← PYNQ 侧
│   ├── build_pynq_rootfs.sh     组装 PYNQ 根文件系统
│   ├── make_sdimage.sh          出 SD 镜像并逐项验证
│   ├── M1_acceptance_check.sh   板上验收（10 项，自带环境自愈）
│   ├── files/resizefs.sh        换掉 AMD 那个会把分区表挪位、导致第二次开机 panic 的版本
│   ├── zocl-kernel-6.12/        zocl 配方 + 三个内核 6.12 补丁
│   └── 参考/                    官方原版留存：PYNQ 的 zocl 设备树片段（poll / intc）、AMD 原版 resizefs.sh
└── xsa/
    └── ax7015b_ps7_complete.tcl 补全 PS7 并重新导出 XSA
```

每个脚本由哪份文档解释，见 [`../../deploy/README.md`](../../deploy/README.md) 的表格。
