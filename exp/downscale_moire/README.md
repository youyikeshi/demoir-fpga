# 分辨率对摩尔纹的影响 —— 实验协议

## 问题

训练集是 **4032×3024 的高分辨率屏摄**（含摩尔纹）。把它们降到低分辨率时，摩尔纹会怎样？
这里有两种**方向相反**的效应，必须分开看：

1. **带限（好）**：低通滤掉摩尔纹的高频 → 摩尔纹变淡甚至消失；
2. **混叠（坏）**：若重采样前低通不够，高频摩尔纹**折叠**到低频 → 变成新的、更难去除的花纹。

实测已验证这个框架能区分两者（`common.py` 冒烟）：

| 算法 | 1/2 | 1/4 | 1/8 | 折叠能量 |
|---|---:|---:|---:|---:|
| Lanczos | 0.335 | 0.103 | 0.092 | 0.0008 |
| 最近邻 | **1.414** | **1.433** | **1.280** | **0.0150** |

即：正确低通让摩尔纹衰减 90%+；最近邻让它**增强 40%**（折叠）。

## 统一口径（不许改）

- 样本：`common.image_list()` 返回的 **10 张**（跨 10 个 pair，顺序固定）
- 裁剪：中心 2048×2048（`common.CROP`）
- 倍率：`common.FACTORS = (2, 4, 8)` → 1024 / 512 / 256
- 评估：`common.evaluate(img_in, img_out_upscaled, factor)`
  - `moire_ratio`：固定频带 0.18~0.50 cyc/px 的能量保留比（越小=摩尔纹去得越多）
  - `alias_lf`：**折叠能量**（低频差异，只能来自混叠）——最关键的坏指标
  - `blur_hf`：模糊能量（高频差异，过度平滑/振铃的代价）
  - `flat_std_out` / `chroma_out`：平坦区对比度与彩色摩尔纹强度
- 上采样回原尺寸仅供**可视化与评估**（各算法统一用 BICUBIC；NEAREST 类算法例外，
  可用 NEAREST 回放以免二次平滑掩盖混叠）
